# HR-Analysis-Power-BI
## Project Purpose
The purpose of this project is to analyze workforce demographics, turnover patterns, and satisfaction levels to help HR leadership identify root causes of employee attrition and implement targeted retention strategies.

## Dataset Used
- <a href= https://github.com/junturajanelle/HR-Analysis-/blob/main/HR%20analytics%20-%20raw.csv> HR Analysis Raw Data</a>
## Key Contributions & Achievements
1. Data Cleaning & Standardization
- Data Sanitization: Removed duplicate records and resolved null values across employee entries to ensure data integrity and accurate totals.
- Standardization: Standardized column formatting, department names, and numerical values across all records for seamless data integration.

2. Data Modeling & DAX Measures
- KPI Calculations: Authored DAX measures to calculate core HR metrics, including Total Employees (1,417), Active Employees (1,186), Attrition Count (231), and Attrition Rate (16.3%).
- Averages & Groupings: Developed measures to dynamically compute Average Age (36.94) and Average Experience (7.04 years), enabling deeper demographic segmentation.
  
3. Visualization & Insight Generation
- Interactive Dashboard Layout: Designed a clean visual layout using card visuals, donut charts, bar graphs, matrix tables, and trendlines to present complex workforce metrics clearly.
- Actionable Insights: Identified key turnover drivers highlighting high attrition in Operations (36%) and among early-tenure employees (1"-" 3 years) providing leadership with data-driven points for retention strategies.
